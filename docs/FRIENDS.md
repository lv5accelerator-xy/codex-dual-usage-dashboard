# Codex 额度：安装与分享指南

这是一个独立开发的 Windows 10/11 桌面工具，用于查看个人和工作 Codex 账号的剩余额度，不是 OpenAI 官方客户端。

## 第一次使用

1. 从固定发布页下载 `CodexUsage.exe`：
   https://github.com/lv5accelerator-xy/codex-dual-usage-dashboard/releases/latest
2. 双击后点击“安装并启动”。无需管理员权限，安装到当前用户目录，并创建桌面与开始菜单快捷方式。
3. 右键悬浮窗或托盘图标 → **账号登录 / 切换**，分别登录自己的个人或工作账号。没有登录的账号不会显示有效额度。
4. 额度每分钟刷新；右键可调整紧凑小窗透明度、开启低额度通知。

需要 Windows .NET Framework 4.8、Windows PowerShell 5.1 和 Codex CLI。账号登录流程可引导安装 CLI；这一步需要网络，CLI 的依赖可能需要额外安装。公司设备的管理策略可能限制安装或运行，请联系管理员。

## 自动更新

启动后及每六小时检查新版本；后台下载后，右键 **客户端更新 → 重启并更新** 即可。正常退出也会安装已下载的新版本。网络不可用时继续使用当前版本，可在同一菜单手动重试。更新保留账号配置、窗口位置与透明度设置。

## 发给朋友

直接分享上面的发布页链接或发布页中的 EXE，让对方登录自己的账号。不要打包自己电脑的账号目录、设置或日志，也不要发送任何 `auth.json`。

程序不会把你的登录信息嵌入分发文件。每个朋友使用各自电脑上的 Codex 账号目录；更新检查连接本项目 GitHub，额度查询和登录使用 Codex CLI 的服务。

## Windows 提示怎么处理

本版没有受信任的发布者数字签名。发布页提供 SHA256SUMS.txt 与 update.json 供核对下载内容；校验值用于检查一致性，不能代替发布者签名，也不代表杀毒认证。

- **“无法识别的应用”/“Windows 已保护你的电脑”**：可能是 SmartScreen 信誉不足，不等于已经检测到病毒。先确认下载来源；系统允许且你确认信任此程序时，可在“更多信息”中选择“仍要运行”。
- **明确报出威胁名称、隔离或删除文件**：先停止运行，记录检测名称、版本和提示截图，通过 GitHub Issues 反馈。开发者可提交微软复审： https://www.microsoft.com/en-us/wdsi/filesubmission
- 不要关闭杀毒软件、添加整个文件夹排除项，或绕过单位的管理策略。

## 卸载与重新安装

先右键托盘图标 → **退出**，再打开 Windows 设置 → 应用 → 已安装的应用（Windows 10 为“应用和功能”），找到 **Codex 额度** 并卸载。

卸载只移除程序和快捷方式，保留 `%LOCALAPPDATA%\CodexUsage\data` 中的设置与日志。不会删除 `%USERPROFILE%\.codex-personal` 或 `.codex-work` 中的登录信息，因为它们也可能被其他 Codex 工具使用。重新安装会继续使用原有设置。

## 从旧脚本版升级

先退出旧程序，将 EXE 放到旧目录首次运行。程序会迁移该目录中的 ui-settings.json 与 profiles.json，已有客户端设置不会被覆盖。

启动问题可查看 `%LOCALAPPDATA%\CodexUsage\client.log` 和 `data\logs`。向他人发送日志前请检查是否含账号或本地路径等私人信息。
