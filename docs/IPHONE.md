# iPhone 使用方法

手机端只查看额度，不会登录 Codex。Codex 登录凭证始终留在你的 Windows 电脑上。

## 第一次设置

### 电脑

1. 启动 **Codex 额度**。
2. 右键任务栏右下角的 Codex 额度图标。
3. 打开 **远程通知与手机额度**。
4. 勾选 **启用手机额度同步**。
5. 如果配对密钥是空的，点 **生成**。
6. 点 **复制密钥**，再点 **保存**。
7. 等待桌面额度完成一次刷新。状态显示“同步正常”后即可使用手机。

“跨电脑完成通知”和“手机额度同步”是两个独立开关。你可以只开启手机额度同步。

### iPhone

1. 用 Safari 打开 `https://lv5accelerator-xy.github.io/codex-dual-usage-dashboard/`。
2. 中继地址保持 `https://ntfy.sh`，除非你在电脑上使用了自己的 ntfy 地址。
3. 输入刚才从电脑复制的配对密钥。
4. 如果这是你自己的受信任手机，可以勾选 **在此设备记住配对密钥**。不勾选时，关闭本次 Safari 会话后可能需要重新输入。
5. 点 **连接**。

第一次可能会显示“等待电脑发送额度…”。回到电脑点一次“立即刷新”，稍等片刻即可。

## 添加到主屏幕

1. 保持 Safari 打开 Codex 额度页面。
2. 点 Safari 底部的 **分享** 按钮。
3. 向下找到 **添加到主屏幕**。
4. 名称保留“Codex 额度”，点右上角 **添加**。
5. 以后直接点主屏幕图标，页面会像普通 App 一样全屏打开。

## 如何刷新

手机上的 **刷新** 只会读取中继服务器里最近的一份数据，不会让电脑立即查询 Codex。Windows 电脑通常每分钟刷新额度；即使数字没变化，也会至少每五分钟发送一次在线心跳。

## 如何判断电脑离线

- 两分钟内更新：显示“Windows 电脑在线”。
- 两到十分钟：显示最近更新时间。
- 超过十分钟：显示“电脑可能离线 / 数据未更新”。
- 超过一天：显示“数据已过期”。

旧数字不会被伪装成实时数据。额度的恢复时间到了以后，手机会显示“等待电脑确认”，不会自行假设额度已经恢复。

## 更换配对密钥

1. 在 Windows 打开 **远程通知与手机额度**。
2. 点 **生成**，再点 **复制密钥** 和 **保存**。
3. 在 iPhone 点右上角 **设置**，输入新密钥，点 **保存并连接**。

旧密钥不能解密使用新密钥发送的快照。

## 手机丢失怎么办

立即在 Windows 重新生成配对密钥并保存。旧手机将无法读取之后发送的新快照。如果你也使用跨电脑完成通知，需要在仍然受信任的另一台电脑上同步更换密钥。

## 清除手机数据

打开右上角 **设置**，点 **清除此设备数据**。这会删除此浏览器保存的中继地址和配对密钥。手机端不会保存 Codex 登录凭证，也不会持久保存解密后的额度快照。

## 常见提示

- **配对密钥不正确或数据已损坏**：重新从 Windows 复制完整密钥。
- **中继服务器无法连接**：检查手机网络和中继地址是否与电脑一致。
- **当前离线**：手机没有网络。页面外壳仍可打开，但无法取得最新额度。
- **Personal / Work 数据读取失败**：该账号在 Windows 上读取失败，请在电脑端重新登录或刷新。
